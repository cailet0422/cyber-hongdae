# 🎬 사이버 홍대입구

**[English README](README.en.md)**

롯데시네마 홍대입구 10층 로비와 **4관 광음시네마**를 3D로 재현한 **온라인 단체관람 공간**입니다.

관리자가 자기 컴퓨터에서 버튼 한 번으로 서버를 열면, 친구들은 **설치 없이 브라우저로 주소만 열어** 캐릭터로 입장합니다. 같은 영화를 같은 장면으로 함께 보면서 채팅하고, 응원봉을 흔들고, 극장 좌석에 앉을 수 있습니다.

## ✨ 무엇을 할 수 있나요?

- **3D 영화관**: Blender 스크립트로 만든 롯데시네마 홍대입구 10층 맵을 돌아다닐 수 있습니다. 4관 광음시네마(스크린, 보라색 LED 서브우퍼, 석재 흡음벽, 그래피티 벽화, 검은 가죽 좌석 187석의 스타디움 객석)와 로비(Sweet# 매점, 키오스크, 창가 바, 로비 전광판, 포스터, 베이비시트, 5관·6관 입구, 화장실)가 있습니다.
- **함께 보기**: 관리자가 튼 영상을 모든 접속자가 **같은 시점**으로 봅니다. 늦게 들어와도 자동으로 맞춰집니다.
- **거의 모든 영상**: 내 PC 영상 파일·폴더, 유튜브 영상·재생목록, 구글 드라이브, 치지직·트위치·SOOP 생방송, mp4·m3u8 링크, 자체 웹서버 폴더 주소 등을 재생합니다.
- **자막**: SMI·SRT·ASS·VTT를 지원하고, MKV 내장 자막과 유튜브 자막도 자동으로 붙습니다.
- **캐릭터 5종**: 유이(빨강)·미오(파랑)·리츠(노랑)·무기(핑크)·아즈사(초록) 컬러의 오리지널 아바타입니다. 입장할 때나 설정에서 바꿀 수 있습니다.
- **내 3D 모델**: 접속자마다 VRM·GLB·FBX·PMX·OBJ 등 자기 모델을 올려 아바타로 쓸 수 있고, 다른 사람에게도 보입니다.
- **무작위 닉네임**: 접속할 때마다 `유이3421`, `리츠1346`처럼 자동으로 정해집니다(친목 방지).
- **응원봉(킹블레이드)**: 방과후 티타임 5색(빨강·파랑·노랑·핑크·초록) 중 고를 수 있고 흔들 수 있습니다.
- **이모트**: 손 흔들기, 박수, 만세, 인사, 춤, 화이팅, 에어 기타, 에어 드럼 등이 있습니다.
- **좌석 착석**: 좌석에 앉으면 관객 시점이 됩니다.
- **관리자 대시보드**: 서버 열기, 상영 관리, 강퇴·밴·채팅 금지, 공지, 로비 전광판 영상, 4관 전광판 문구를 모두 GUI로 다룹니다.

## 💾 설치하기 (Windows)

> 설치 파일 하나에 필요한 모든 것(관리자 프로그램, 영상 도구 ffmpeg·yt-dlp, 인터넷 공개 도구 cloudflared)이 들어 있습니다. **Node.js 등 다른 프로그램을 따로 설치할 필요가 없습니다.**

### 1단계 – 설치 파일 받기

**[📥 Releases 페이지](https://github.com/cailet0422/cyber-hongdae/releases/latest)** 에 들어가서 **`CyberHongdae-Setup-x.x.x.exe`** 를 누르면 다운로드됩니다(약 200MB).

### 2단계 – 설치하기

1. 받은 **`CyberHongdae-Setup-x.x.x.exe`** 를 더블클릭합니다.
2. **「Windows의 PC 보호」** 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요. 개인이 만든 무료 프로그램이라 코드 서명 인증서가 없어서 뜨는 안내이고, 프로그램에는 문제가 없습니다.
3. 설치 마법사에서 **다음 → 설치**를 누릅니다. 설치 폴더는 그대로 두어도 됩니다.
4. **마침**을 누르면 프로그램이 바로 실행됩니다.

설치가 끝나면 **바탕화면과 시작 메뉴에 「사이버 홍대입구 관리자」** 바로가기가 생깁니다.

> - 관리자 권한이 필요 없습니다. 내 사용자 폴더에 설치됩니다.
> - 설정·재생목록·다운로드한 영상은 `%APPDATA%\cyber-hongdae\data` 에 저장됩니다.
> - 지울 때는 **Windows 설정 → 앱 → 설치된 앱 → CyberHongdae → 제거**를 누르세요.
> - **자동 업데이트**: 프로그램이 새 버전을 스스로 확인하고 내려받습니다. 상영이 끊기지 않도록 프로그램을 닫을 때 설치되며, 관리자 화면 위쪽의 **지금 재시작하고 업데이트** 버튼으로 바로 설치할 수도 있습니다. **설정 → 프로그램 업데이트**에서 끄거나 직접 확인할 수 있습니다.

## 🚀 서버 열기

1. 바탕화면의 **「사이버 홍대입구 관리자」** 를 실행합니다.
2. **서버** 탭에서 **공개 방식**을 고릅니다. 처음이라면 기본값(인터넷 공개)을 그대로 쓰세요.
3. **🚀 서버 열기**를 누릅니다.
4. 10초 정도 지나면 초록색 상자에 주소가 나옵니다. **📋 주소 복사**를 눌러 카톡이나 디스코드로 친구들에게 보내면 됩니다. QR 코드로 휴대폰 접속도 할 수 있습니다.
5. 나도 같이 보려면 **🎮 내 브라우저로 입장**을 누르세요.

### 공개 방식 비교

| 방식 | 설정 | 주소 | 내 IP 노출 | 추천 상황 |
|---|---|---|---|---|
| **인터넷 공개 (Cloudflare)** | 필요 없음 | 열 때마다 바뀜 (`https://○○○.trycloudflare.com`) | ❌ 숨겨짐 | 처음 써볼 때, 가장 쉬움 |
| **Tailscale Funnel** | Tailscale 설치·로그인 | **고정** (`https://내PC이름.○○○.ts.net`) | ❌ 숨겨짐 | 매번 같은 주소를 쓰고 싶을 때 |
| **포트포워딩 자동 (UPnP)** | 공유기가 UPnP 지원 | 내 IP (`http://123.45.67.89:7777`) | ⚠️ 공개됨 | 공유기 설정에 익숙할 때 |
| **같은 와이파이만** | 필요 없음 | `http://192.168.○.○:7777` | 집 안에서만 | 가족·룸메이트와 볼 때 |

> 💡 서버를 연 컴퓨터가 꺼지거나 잠자기에 들어가면 서버도 멈춥니다. 상영 중에는 절전 모드를 꺼 두세요.

## 🛡 Tailscale로 IP 숨기고 공개하기

Tailscale Funnel을 쓰면 **내 집 IP를 숨긴 채** 항상 같은 주소로 서버를 공개할 수 있습니다. 접속자는 Tailscale을 설치할 필요가 없습니다.

### 처음 한 번만 설정

1. <https://tailscale.com/download> 에서 Tailscale을 설치합니다.
2. 작업 표시줄의 Tailscale 아이콘을 눌러 **Log in** 합니다(구글·마이크로소프트·깃허브 계정 사용 가능).
3. <https://login.tailscale.com/admin/dns> 에서 **MagicDNS**와 **HTTPS Certificates**가 켜져 있는지 확인합니다. 둘 다 Enable 버튼을 누르면 됩니다.

### 서버 열기

1. 관리자 프로그램에서 공개 방식을 **Tailscale Funnel (IP 숨김)** 으로 고릅니다.
2. **🚀 서버 열기**를 누르면 `https://내PC이름.○○○.ts.net` 주소가 나옵니다.

> 처음 쓸 때 "이 tailnet에서 Funnel이 꺼져 있습니다"가 나오면, 아래의 **🔗 허용 페이지 열기** 버튼을 눌러 한 번만 허용하고 다시 서버를 여세요.

- 서버를 닫으면 Funnel 설정도 자동으로 꺼집니다. 다른 Tailscale 설정은 건드리지 않습니다.
- Funnel은 443·8443·10000번 포트만 쓸 수 있습니다. 이미 쓰는 포트가 있으면 비어 있는 포트를 자동으로 고릅니다.

## 🎞 영화 틀기

관리자 프로그램의 **🎬 상영 관리** 탭에서 합니다.

### 파일·폴더

- **📄 파일 추가** 또는 **📁 폴더 추가**를 누르거나, 파일·폴더를 창으로 **끌어다 놓으세요**.
- 영상과 **같은 이름의 자막**(예: `영화.mp4` + `영화.smi`)은 자동으로 붙습니다.
- 브라우저가 재생하지 못하는 형식(MKV, AVI, HEVC, AC3 음성 등)은 자동으로 변환됩니다. NVIDIA 그래픽카드가 있으면 더 빠릅니다.

### 링크

링크를 입력 칸에 붙여넣고 **🔗 링크 추가**를 누릅니다. 여러 줄을 한 번에 넣어도 됩니다.

| 종류 | 예 |
|---|---|
| 유튜브 영상·재생목록 | `https://www.youtube.com/watch?v=...`, `https://www.youtube.com/playlist?list=...` |
| 구글 드라이브 파일·폴더 | `https://drive.google.com/file/d/...` (링크 공유: "링크가 있는 모든 사용자") |
| 생방송 | 치지직, 트위치, SOOP, 유튜브 라이브 |
| 직접 링크 | `https://.../movie.mp4`, `https://.../stream.m3u8`, 드롭박스 공유 링크 |
| 자체 웹서버 폴더 | `http://내서버/영화/` (폴더 목록 페이지의 영상과 자막을 모두 가져옴) |
| 기타 | yt-dlp가 지원하는 수천 개 사이트 (비메오, 니코니코, 빌리빌리 등) |

**재생 방식**은 두 가지입니다.

- **미리 받아서 재생 (기본)**: 관리자 PC에 받아 두고 재생합니다. 가장 안정적이고 고화질입니다.
- **바로 스트리밍**: 받지 않고 바로 재생합니다. 빠르지만 원본 사이트 사정에 따라 끊길 수 있습니다. 생방송은 자동으로 이 방식을 씁니다.

### 재생 조작

- ▶/⏸ 재생·일시정지, ⏮⏭ 이전·다음, ⏹ 정지
- 진행 막대를 끌어 **탐색**하면 모든 접속자가 같이 이동합니다.
- 🔁 전체 반복 / 🔂 한 개 반복 / ➡ 반복 안 함
- 목록에서 ↑↓로 순서를 바꾸고, ▶로 바로 재생하고, 🗑로 삭제합니다. 제목을 더블클릭하면 이름을 바꿀 수 있습니다.
- 자막 칸에서 자막을 고르거나 **+ 자막 파일 추가…** 로 붙입니다.

## 📺 전광판 꾸미기

**📺 전광판** 탭에서 합니다.

- **4관 입구 전광판**: 관 이름, 층, 영화 제목(현재 상영작을 자동으로 표시하거나 직접 입력), 안내 문구, 영문 문구, 글자색, 시계, 배경 이미지를 바꿀 수 있습니다. 위쪽 미리보기로 확인한 뒤 **전광판 문구 적용**을 누르세요.
- **로비 전광판**: 창가 쪽 대형 LED에 영상, 이미지, 링크를 반복 재생합니다. 아무것도 고르지 않으면 포스터 슬라이드와 상영 정보가 나옵니다.

## 👮 접속자 관리

- **👥 접속자** 탭: 닉네임, 캐릭터, IP, 좌석, 접속 시간을 봅니다.
  - **채팅 금지**: 채팅만 막습니다.
  - **강퇴**: 내보냅니다. 다시 들어올 수는 있습니다.
  - **밴**: 같은 IP와 같은 기기로 다시 못 들어오게 막습니다. 차단 목록에서 해제할 수 있습니다.
- **💬 채팅** 탭: 채팅을 실시간으로 보고, **📢 공지**를 보내고(노란 글씨로 크게 표시), 슬로우 모드를 켜고, 채팅을 끄거나 기록을 지웁니다.
- **⚙️ 설정** 탭: 서버 이름, 최대 인원, 영상 최대 화질, 닉네임에 쓸 이름 목록, 응원봉 5색을 바꿉니다.

- 극장 밖(로비)에서는 영화 소리가 벽 너머처럼 작고 먹먹하게 들립니다.

## 🧸 내 3D 모델로 입장하기

접속자는 누구나 **자기 3D 모델을 올려서 자기 아바타로** 쓸 수 있습니다. 올린 모델은 다른 접속자 화면에도 그대로 보입니다.

### 올리는 방법

- **입장 화면**의 「내 3D 모델」에서 **📂 모델 파일** 또는 **📁 모델 폴더**를 누릅니다.
- 입장한 뒤에는 **Esc → 설정 → 내 3D 모델**에서 바꿀 수 있습니다.
- 한 번 올린 모델은 기억되어 다음 접속 때 자동으로 적용됩니다. **기본 캐릭터로** 버튼을 누르면 해제됩니다.

### 지원 형식

| 형식 | 설명 |
|---|---|
| **VRM** (0.x / 1.0) | VRoid Studio 등에서 만든 아바타. 표정(눈 깜빡임, 웃음 등)까지 지원하는 가장 추천하는 형식 |
| **GLB / GLTF** | 범용 3D 형식. GLTF는 `.bin`·텍스처와 함께 폴더나 ZIP으로 올리세요 |
| **FBX** | Mixamo, Unity·Blender에서 내보낸 모델 |
| **PMX / PMD** | MMD 모델. 텍스처가 따로 있으니 **폴더째** 올리세요 |
| **OBJ** (+MTL) | 정적 모델. `.mtl`과 텍스처를 함께 올리세요 |
| **DAE** (Collada), **3DS**, **STL**, **PLY** | 그 밖의 형식 (STL·PLY는 텍스처 없음) |
| **ZIP** | 위 형식을 텍스처와 함께 압축한 파일. 한국어·일본어 파일 이름도 인식합니다 |

### 움직임은 어떻게 되나요?

- **사람 모양 뼈대(휴머노이드)** 가 있으면 걷기, 달리기, 점프, **좌석 착석**, 이모트, 응원봉이 기본 캐릭터와 똑같이 동작합니다. VRM 휴머노이드, Mixamo, Unity, Blender, Unreal, 3ds Max Biped, Daz/CC, MMD(일본어 본 이름)의 뼈 이름을 자동으로 알아봅니다.
- 뼈대가 없거나 알아볼 수 없는 모델은, 모델 안에 애니메이션(idle, walk, run 등)이 있으면 그것을 재생하고, 없으면 통통 튀며 움직입니다.
- 키는 자동으로 1.6m에 맞춰지고, 앞뒤 방향도 자동으로 판단합니다. **설정 → 키**, **앞뒤 반전**으로 직접 조절할 수 있습니다.

### 알아두세요

- 파일 크기는 기본 **최대 60MB**(관리자가 변경 가능), 폴리곤은 **50만 개까지**입니다.
- 무거운 모델이 많으면 화면이 느려질 수 있습니다. **설정 → 「다른 사람의 커스텀 모델 보기」** 를 끄면 다른 사람은 기본 캐릭터로 보입니다.
- 관리자는 **접속자 탭 → 모델 초기화**로 부적절한 모델을 기본 캐릭터로 되돌리고, **설정 탭**에서 커스텀 모델을 아예 끌 수 있습니다.
- 다른 사람이 만든 모델은 그 모델의 이용 규약을 지켜서 사용하세요.

## ❓ 자주 묻는 질문 / 문제 해결

**Q. 친구가 접속하면 끊기거나 버벅여요.**
접속자 전원이 관리자 PC에서 영상을 받습니다. 1080p는 1명당 약 5Mbps라서 30명이면 업로드가 150Mbps 필요합니다. **⚙️ 설정 → 영상 최대 화질**을 720p로 낮추세요. 인터넷 속도 측정 사이트에서 **업로드** 속도를 확인해 보세요.

**Q. "포트 7777이 이미 사용 중입니다"가 나와요.**
서버 탭에서 포트를 7778처럼 다른 숫자로 바꾸세요.

**Q. 유튜브 링크가 실패해요.**
유튜브가 바뀌면 yt-dlp를 업데이트해야 할 때가 있습니다. 최신 설치 파일로 다시 설치하거나, 설치 폴더(기본 `%LOCALAPPDATA%\Programs\CyberHongdae`)의 `resources\tools\bin` 에서 다음을 실행하세요.

```bash
yt-dlp.exe -U
```

**Q. 백신이 설치 파일을 막아요.**
코드 서명이 없는 개인 프로그램이라 일부 백신이 확인을 요청할 수 있습니다. 이 저장소의 Releases에서 받은 파일인지 확인한 뒤 허용하세요.

**Q. 포트포워딩 방식이 실패해요.**
공유기 UPnP가 꺼져 있을 수 있습니다. **인터넷 공개(Cloudflare)** 나 **Tailscale Funnel**을 쓰세요. 둘 다 공유기 설정이 필요 없습니다.

**Q. 접속자는 무엇을 설치해야 하나요?**
아무것도 필요 없습니다. 크롬·엣지·웨일·사파리 등 최신 브라우저로 주소만 열면 됩니다. 그래픽이 약한 PC나 휴대폰은 **Esc → 그래픽 품질 「낮음」**, **최대 표시 인원**을 줄이면 부드러워집니다.

**Q. 관리 화면 없이 서버만 돌릴 수 있나요?**
소스로 설치한 경우 `서버만 실행 (GUI 없이).bat`을 쓰세요(Cloudflare 터널로 공개). 같은 PC 브라우저에서 `http://localhost:7777/admin?token=local-admin` 으로 관리 화면을 쓸 수 있고, 외부에서는 접근할 수 없습니다.

## 🛠 개발자용 정보

### 소스로 설치하기 (개발자용)

[Node.js](https://nodejs.org) LTS를 설치한 뒤 저장소를 받고, **`처음 설치.bat`** 을 실행합니다. npm 패키지, Electron, 영상 도구를 받고 바탕화면 바로가기를 만듭니다. 설치 파일을 직접 빌드하려면 다음을 실행하세요.

```bash
cd app
npm install
node scripts/setup-tools.js
npm run dist          # ../dist/CyberHongdae-Setup-x.x.x.exe 생성
```

```bash
cd app

node server/standalone.js --port 7777 --expose tunnel|tailscale|upnp|lan --admin-token 비밀값
node scripts/bots.js 80 ws://localhost:7777/ws 60   # 부하 테스트 봇
```

### 맵 다시 만들기 (Blender 4.2)

<https://www.blender.org> 에서 Blender 4.2를 설치한 뒤 실행합니다.

```bash
cd app/blender
python make_textures.py        # 글자가 들어가는 간판 등 절차 텍스처
python compose_ai.py           # AI 텍스처 합성 + poster 폴더 포스터 아틀라스
blender -b -P build_cinema.py -- --render
```

평면도 좌표는 `build_cinema.py` 맨 위의 `U()`/`V()`(손그림 1px = 7.5cm)를 기준으로 합니다. 결과물은 `client/assets/map/cinema.glb`와 `cinema.blend`입니다.

### 동기화 방식

서버가 `(재생 위치, 서버 시각)`을 보내면, 클라이언트는 핑으로 시계 차이를 보정한 뒤 1.5초 이상 어긋나면 탐색하고, 그보다 작으면 재생 속도를 ±10% 조절해 따라잡습니다. 위치 동기화는 변경분만 10Hz로 보냅니다. 봇 80명 접속 상태에서 클라이언트가 130fps로 측정되었습니다(RTX급 GPU 기준).
